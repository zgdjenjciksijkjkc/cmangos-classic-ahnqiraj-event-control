# 已归档的可选表现增强草案

## 状态

此目录不是运行事件 120-123 所需的核心补丁，也没有部署到 `mangosd.exe`。

游戏内实测已经证明，SHA256 为
`FC4CEC8D5861DBEFEF34745434235B9F7531B5DAC580D8BAB80FB83F0F5811AC`
的 Larmer Build 能在任务 8743 完成后自动执行以下关键流程：

- 从事件 122 切换到事件 123；
- 开放大门并移除碰撞；
- 启动战争计时；
- 生成事件 123 军队和共鸣水晶；
- 发送 `broadcast_text 11432`。

未观察到 `broadcast_text 11427`、三层门体开启动画或原生声音。因为这些表现
不影响核心玩法，本包不会为它们替换现有 EXE。

## 已推翻的旧假设

早期草案曾假设 `world_state.Id=1`：

- 第 2 字段是毫秒倒计时；
- 第 35 字段是可由脚本写入的 `GatesOpen` 标志。

实测表明这两项假设不能用于当前 Larmer Build：

- 事件 123 的第 2 字段是 Unix 到期时间戳（秒）；
- 大门成功开放后第 35 字段仍为 `0`。

因此 `war_effort_gong_transition.reference.cpp` 已通过 `#if 0` 整体禁用，只保留
为历史研究资料，绝不能直接编译或移植。

## 若以后继续研究动画和广播

只有同时满足下列条件时才应建立新的源码方案：

1. 取得与目标 `mangosd.exe` 完全匹配的源代码和符号；
2. 从该源码确认 35 个字段的真实结构和持久化单位；
3. 找到任务 8743 的实际奖励回调和现有阶段转换路径；
4. 在独立测试端验证动态 GameObject 状态、碰撞和重启恢复；
5. 保持当前已经通过验收的 122→123 流程可回退。

不得把本目录的旧常量、字段名称或十秒状态机当成已验证事实。
