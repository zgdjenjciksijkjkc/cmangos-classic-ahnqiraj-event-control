# Contributing

Please open an issue before expanding the project scope.

Contributions should:

- target CMaNGOS Classic / WoW 1.12.x;
- include exact core/database version details and reproduction steps;
- prefer verified data fixes for data-owned behavior;
- preserve schema validation, automatic backups, and rollback paths;
- document affected event, GUID, quest, NPC, faction, and table IDs;
- avoid executables, client files, database dumps, credentials, and private logs.

The Ahn'Qiraj opening/Scepter quest chain is planned future work. Do not present
an untested quest-chain or core patch as part of the verified v1.0.0 feature set.
